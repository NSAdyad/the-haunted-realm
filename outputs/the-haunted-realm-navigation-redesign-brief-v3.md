# The Haunted Realm — navigation redesign review brief

Status: Option B revision v2 is rejected and NOT APPROVED. This brief authorizes static visual review mock-ups only. No navigation, activity pages, activity cards, or website implementation is authorized.

## Problems recorded before another version

1. Openness was treated mainly as larger gaps between opaque plaques. The destination objects themselves still felt heavy, rather than allowing scenery through the structure.
2. Dark oak and bronze plaques repeated too much of the approved Ancient Village Sign title. Navigation needs a distinct complementary identity.
3. Decorative wooden signage did not provide the requested eerie, supernatural, gothic haunted atmosphere.
4. The treatment felt like illustrated fantasy interface decoration. Real materials, cinematic lighting, believable corrosion, glass and supporting hardware need to lead the design.

## New visual review direction

Individual suspended destinations in a sparse corroded iron structure, with aged clear/smoked glass label surfaces. Scenery must be visible both between destinations and through the glass; text remains opaque and immediately readable. Use restrained weathering, fine cobweb strands and eerie edge reflections. Current-page illumination remains localized to that destination. Avoid oak nameplates, repeated title ornaments, polished fantasy bronze, modern button selection outlines, invented thematic icons and final activity imagery.

## Functional concept retained

- Horizontal Home navigation; vertical left-side activity navigation.
- Home and temporary numbered activity labels only.
- Clearly temporary image spaces, awaiting future realistic activity illustrations.
- An identifiable current page.
- A complete-list/continuation cue demonstrating future expansion; no fixed activity-count commitment.

## Protected elements

Use the exact approved 1536 x 1024 background and exact 650 x 215 title at x=443, y=65. Never send either to image generation as an edit target. Preserve original files, title placement and scale. Generate only separate, unapproved navigation materials, then produce separate raster mock-ups. Verify protected hashes and pixels before presentation.

## Quality review before presentation

Compare directly against rejected v2: genuinely transparent destinations and open structure; more visible scenery; distinct identity; stronger haunted atmosphere; more physically believable material/lighting; readable names; no emoji/cartoon/generic icons; concept remains expandable. Correct a failed review before presenting. The user's visual approval is still required; no navigation protection or implementation follows automatically.
